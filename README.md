# Sky

**TypeScript-declarative. Rust-runtime. Bun-powered.**

Sky is a web framework where TypeScript describes your services and the Rust gateway handles everything else — HTTP, worker supervision, routing, middleware, and observability. Write handlers with decorators, let Sky run them at scale.

```ts
@Service({ lifetime: "scoped" })
export class UserService {
  @Handler({ method: "POST", path: "/users", extract: { body: ZodBody(CreateUserSchema) } })
  async createUser({ body }: { body: z.infer<typeof CreateUserSchema> }) {
    return { id: crypto.randomUUID(), ...body };
  }
}
```

> **Pre-alpha.** Public APIs are unstable until 1.0.

---

## How it works

Sky separates concerns cleanly across two runtimes:

- **Rust gateway** — binds the HTTP port, validates requests against a compiled manifest, routes invocations over a Unix domain socket to a pool of Bun workers, and handles restarts, rate limiting, CORS, and JWT auth.
- **Bun workers** — run your TypeScript business logic. Each handler is a plain async method on a `@Service`-decorated class. Workers are supervised by the gateway and hot-swapped on crash with no dropped connections.

The two sides share a binary framing protocol (Sky framing) over UDS — no gRPC, no HTTP/2, no codegen.

## Quickstart

```bash
bunx create-sky-app my-app
cd my-app
bun install
bun run build          # emit sky-manifest.json
```

Then start the gateway:

```bash
# Download from GitHub Releases (see releases page)
./sky-gateway --config sky.toml

# Or Docker
docker run --rm -v "$(pwd)":/app -p 8080:8080 ghcr.io/sky-framework/sky:latest
```

Test it:

```bash
curl -X POST http://localhost:8080/hello \
  -H "Content-Type: application/json" \
  -d '{"name": "World"}'
# → {"message":"Hello, World!"}
```

Download the pre-built binary for your platform from [GitHub Releases](https://github.com/sky-framework/sky/releases):

|---|---|
| Linux x86_64 | `sky-gateway-linux-amd64` |
| Linux ARM64 | `sky-gateway-linux-arm64` |
| macOS Apple Silicon | `sky-gateway-macos-arm64` |
| macOS Intel | `sky-gateway-macos-amd64` |

### npm package

```bash
bun add sky-framework
```

Provides the `@Service`, `@Handler`, and extractor decorators, the `startServer` runtime, and the `sky` CLI.

## Project structure

A Sky project has two parts:

```
my-app/
├── sky.toml              # Gateway config (listen, worker, middleware)
├── sky-manifest.json     # Generated by `sky build` — do not edit
├── index.ts              # Worker entry point
└── src/services/
    └── user.ts           # @Service classes live here
```

**`sky.toml`** — minimal example:

```toml
version = "1"

[listen]
address = "0.0.0.0:8080"

[worker]
bun_path = "bun"
worker_script = "./index.ts"
worker_version = "0.1.0"
pool_size = 4

[build]
sources = ["./src/services"]
```

**`index.ts`** — worker entry point:

```ts
import { startServer, logger } from "sky-framework/runtime";
import { UserService } from "./src/services/user";

const server = await startServer({
  workerVersion: "0.1.0",
  logger,
  services: [UserService],
});

process.on("SIGINT", () => server.close());
process.on("SIGTERM", () => server.close());
```

## Decorator API

```ts
import { Service, Handler, Body, Param, Query, Header, ZodBody, Context } from "sky-framework/decorators";
import type { RequestContext } from "sky-framework/runtime";
import { z } from "zod";

@Service({ lifetime: "singleton" | "scoped" })
@Group({ prefix: "/api" })
class MyService {
  // Path parameter
  @Handler({ method: "GET", path: "/items/:id", extract: { id: Param("id") } })
  async getItem({ id }: { id: string }) { ... }

  // Zod-validated body (also validated at gateway before forwarding)
  @Handler({ method: "POST", path: "/items", extract: { body: ZodBody(CreateSchema) } })
  async createItem({ body }: { body: z.infer<typeof CreateSchema> }) {
    return new Response(result).status(201);
  }

  // Query + header extractors
  @Handler({ method: "GET", path: "/search", extract: { q: Query("q"), token: Header("x-token") } })
  async search({ q, token }: { q?: string; token?: string }) { ... }

  // Full request context (JWT claims, typed body, request metadata)
  @Handler({ method: "POST", path: "/secure", extract: { ctx: Context<CreateSchema>() } })
  async secureEndpoint({ ctx }: { ctx: RequestContext<CreateSchema> }) {
    const { sub } = ctx.claims ?? {};
    return { user: sub, body: ctx.body };
  }
}
```

Throwing `HttpError(status, message)` sends an error response:

```ts
import { HttpError } from "sky-framework/runtime";

throw new HttpError(404, "Item not found");
```

## Built-in middleware

```ts
import { requireAuth, cors, rateLimit } from "sky-framework/runtime";

@Handler({
  method: "GET",
  path: "/admin/report",
  middleware: [requireAuth(), cors({ origins: ["https://example.com"] })],
})
async report() { ... }
```

Gateway-level middleware (configured in `sky.toml`):

```toml
[rate_limit]
redis_url = "redis://localhost:6379"
pool_size = 4
command_timeout = "2s"
```

## Docker

Use the official base image and copy your worker files:

```dockerfile
FROM ghcr.io/sky-framework/sky:0.1.0
COPY index.ts sky.toml sky-manifest.json ./
COPY src/ ./src/
RUN bun install --production
CMD ["sky-gateway", "--config", "sky.toml"]
```

A `docker-compose.yaml` is included in the demo for a gateway + Valkey (Redis-compatible) stack.

## Architecture

```
HTTP client
    │
    ▼
┌─────────────────────────────┐
│  sky-gateway (Rust/axum)    │  Validates JSON schema, runs CORS/auth/rate-limit,
│  Manifest-driven router     │  maintains worker pool, handles restarts
└────────────┬────────────────┘
             │ Sky framing protocol
             │ (binary, Unix domain socket)
             ▼
┌─────────────────────────────┐
│  Bun workers (TypeScript)   │  DI container, dispatcher, handler methods,
│  @Service / @Handler        │  Zod validation, streaming, JWT claims
└─────────────────────────────┘
```

The gateway and workers share a manifest (`sky-manifest.json`) emitted by `sky build`. The manifest is the contract — it drives the Rust router and the TypeScript dispatcher independently.
